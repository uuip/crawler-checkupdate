# 五种异步实现对比

本项目以网络 I/O 为主，默认优先 `impl_stream`：结构直接，能限制同时处理的应用数量，也能借用外层数据。需要独立任务管理时选 `impl_joinset`；需要集中写库、汇总状态时选 `impl_channel`。没有脱离工作负载的绝对性能排名。

## 机制与适用场景

| 实现 | 当前代码的机制 | 适用场景与取舍 |
| --- | --- | --- |
| [impl_stream](../impl_stream/src/main.rs) | `for_each_concurrent` 在同一父任务内推进多个 Future；状态使用 `Mutex<HashMap>` | 批量或流式 I/O，子操作需要借用外层数据。没有逐项 `spawn` 的任务开销；这些子 Future 不会跨线程并行执行，单个操作中的同步耗时工作会拖住其他操作。 |
| [impl_stream_dashmap](../impl_stream_dashmap/src/main.rs) | 与 Stream 相同的调度方式，状态改为 `DashMap` | 学习并发容器。分片锁主要适合多个独立任务或线程频繁访问分散的键；当前调度方式、短暂状态更新和少量分类键难以体现优势。 |
| [impl_joinset](../impl_joinset/src/main.rs) | 每项 `spawn` 为独立 Tokio 任务，由 `JoinSet` 管理并逐个回收 | 需要动态增减任务、及时处理完成结果、统一取消任务组。多线程 runtime 可并行调度；`spawn` 要求 Future 满足 `Send + 'static`。当前示例先提交全部任务，再回收结果。 |
| [impl_join](../impl_join/src/main.rs) | 全量读取应用，逐项 `spawn`，再 `join_all` 等待句柄集合 | 有限、预先确定的批次，需要整批完成后统一取得结果。结构简单，但保留整批句柄并等待最慢任务；不提供任务组自动取消。 |
| [impl_channel](../impl_channel/src/main.rs) | 独立任务抓取，`mpsc` 传递结果，单消费者串行写库并持有普通 `HashMap` | 抓取与落库分阶段、集中输出或后续需要批量写入。状态无需共享锁；吞吐也受消费者处理速度影响，生产者生命周期需另外管理。 |

## 影响选择的区别

- **结果顺序**：`join_all` 返回的结果按输入顺序排列，不约束任务执行、打印或写库顺序；`JoinSet` 按完成顺序取结果；Channel 按消息入队顺序消费。当前 Join 示例没有使用返回的结果集合。
- **生命周期**：丢弃 Stream 驱动 Future 会同时丢弃其内部子 Future；丢弃 `JoinSet` 会请求中止组内任务；丢弃 `JoinHandle` 会让任务继续运行。Channel 关闭也不会自动取消生产者。取消不能撤销已经完成的外部写入。
- **并发与背压**：Stream 的并发上限限制活跃子 Future；Channel 容量只限制排队消息，队列满后发送端异步等待，不限制此前已启动的抓取任务。JoinSet、Join 和 Channel 都可以另加任务准入控制。应按连接池、服务限流和内存预算设置参数，不能凭示例中的容量数值评价方案。
- **可组合性**：DashMap 解决共享状态访问，Channel 解决阶段间通信，JoinSet 解决任务管理，它们不是互斥选项。例如可用 JoinSet 管理抓取任务，再由 Channel 将结果交给单个写入者。只有确实需要这些职责时才组合。

这里的 `impl_join` 是 **`spawn + join_all(JoinHandle)`**，不是 `tokio::join!`，也不是直接合并未派生为任务的 Future；独立调度能力来自 `spawn`。

API 依据：[for_each_concurrent](https://docs.rs/futures/latest/futures/stream/trait.StreamExt.html#method.for_each_concurrent)、[join_all](https://docs.rs/futures/latest/futures/prelude/future/fn.join_all.html)、[JoinSet](https://docs.rs/tokio/latest/tokio/task/struct.JoinSet.html)、[JoinHandle](https://docs.rs/tokio/latest/tokio/task/struct.JoinHandle.html)、[mpsc](https://docs.rs/tokio/latest/tokio/sync/mpsc/index.html)、[DashMap](https://docs.rs/dashmap/latest/dashmap/struct.DashMap.html)。
